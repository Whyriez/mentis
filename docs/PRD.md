# Product
Mentis – Adaptive Brain Training Platform

## Vision
Mentis helps learners master mental math, logical reasoning, and psychometric skills through structured learning, adaptive practice, and measurable progress.

## Problem
Most learners fail psychometric tests because:
- Basic arithmetic is not automatic.
- They panic under time pressure.
- Existing platforms focus on testing rather than improving.

## Solution
Mentis combines:
- Learning modules
- Mental math techniques
- Timed drills
- Quiz engine
- Analytics
- Adaptive roadmap
- AI-assisted content generation

## MVP
- Authentication

- Learn
- Practice
- Quiz
- Results
- Progress
