# Feature Specification

## 1. Dashboard
Displays:
- Today's goal
- Study streak
- Progress
- Continue learning
- Recent quiz

## 2. Learn
- Module list
- Lessons
- Examples
- Quick tricks
- Summary
- End-of-lesson quiz

## 3. Practice
User selects:
- Module
- Difficulty
- Question count
- Seconds per question

## 4. Quiz
Requirements:
- Timer
- Auto next
- Keyboard shortcuts
- Pause (optional)
- Final result

## 5. Result
Show:
- Accuracy
- Avg response time
- Wrong answers
- Explanation
- Review recommendation

## 6. Analytics
- Accuracy chart
- Time chart
- Weak topics
- Strong topics
- Readiness score

## 7. Roadmap
Generated from:
- Initial assessment
- Weak topics
- Daily goal
- Target months

## 8. Review Queue
Wrong answers are scheduled for spaced repetition.

## 9. Basic Arithmetic Mastery & Progressive Drills
- Progressive Tiers:
  - Multiplication: 1–10 Fundamental (Random), 1–20 (Double-digit/teens), 1–30 (Intermediate), 1–100 (Advanced mental math: near base 100, squaring ending in 5, sandwich 11)
  - Subtraction: 1–20 (Bridging 10 reflex), 1–50 (Tens compensation -9, -19, -29), 1–100 (Base 100 complement & distance method), 1–1000 (3-digit mental subtraction)
  - Division: 1–10 (Inverse table recall), 1–20 (Teens & tens), 1–50 (÷5 & ÷25 speed shortcuts), 1–100 (Factoring & halving)
  - Addition: 1–20 (Bridging 10/20), 1–50 (Compensation), 1–100 (Left-to-right tens), 1–1000 (3-digit mental)
- Customization: 5/10/15/20 question counts, 5s Blitz, 10s Normal, 15s Relaxed, or Untimed practice mode
- Procedural distractors generation and step-by-step mental shortcut explanations

## 10. Bilingual Support (ID / EN)
- Real-time language switcher (`🇮🇩 ID` / `🇬🇧 EN`) accessible globally in Header and inside arithmetic/quiz views
- LocalStorage persistence (`mentis_lang_pref`)
- Complete bilingual UI copy, questions, options, keyboard shortcut tips, and worked mental explanations
